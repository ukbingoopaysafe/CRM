## 🛠️ المواصفات التقنية للنظام (Tech Stack)
* **Backend Framework:** Laravel 12 (PHP 8.2+)
* **Admin & UI Engine:** FilamentPHP v3
* **Database:** MySQL 8.x (عبر XAMPP)
* **Design & UX:** واجهة عربية أولاً بنظام RTL، تصميم عصري فائق السرعة متوافق مع كافة الشاشات.
